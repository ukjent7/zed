# Paths whose strings may reach AI models. GUI translation must only touch
# what is rendered, never what is sent to a model.
#
# Single source of truth, read by:
#   - script/check-l10n-boundary  (refuses `locale::` anywhere in them)
#   - script/check-l10n-dict.py   (a dictionary entry whose English source
#                                  exists only inside one of them is a
#                                  violation)
#   - script/l10n-audit.py        (skipped when listing untranslated GUI
#                                  candidates, so they cannot be mistaken for
#                                  translation gaps)
#
# Being listed is not a claim that a path is model-facing-only (agent_ui and
# context_server mix GUI and model-bound strings); it means "do not translate
# anything here without checking".
#
# One path per line; a directory entry ends with `/`. Text after `#` is a
# comment. Empty lines are ignored.
